# 玄玑 · 中华文化历

玄幻风格的中华文化日历单页应用:深空靛蓝 × 流金配色,全站半透明琉璃面板层叠,内置可拖拽的**三维浑天罗盘**。

## 功能

- **阴阳历** — 公历/农历互转,闰月、大小月、农历节日自动对应(数据表覆盖 1900—3000 年)
- **廿四节气** — 历表定"日" + VSOP87 天文算法定"时分",精确到分钟(北京时间)
- **节日体系** — 七大类彩色标记:公共节日 / 传统节日 / 节气 / 道教 / 佛教 / 民族 / 伊斯兰,图例可点选筛选
- **乾坤八卦** — 后天八卦轮盘(点击查看卦象、五行、方位、卦德),文王六十四卦"玄机一占"铜钱起卦(含变卦)
- **当日命盘** — 四柱干支(立春分界、节气定月)、纳音、建除十二神宜忌、星座、月相、伊斯兰历日期
- **三维罗盘** — Canvas 手写 3D 投影:二十八宿 / 廿四节气 / 十二地支 / 十天干 / 八卦五重环轨 + 太极天心,支持拖拽旋转、滚轮缩放、闲时自转

## 运行

直接双击 `index.html` 即可(纯静态、无构建、无网络依赖;联网时加载思源宋体,离线自动回退楷体)。

或启动本地服务器:

```bash
python ../_ref/serve.py 8772 .
# 打开 http://127.0.0.1:8772/
```

## 数据与算法说明

| 模块 | 来源 |
| --- | --- |
| 农历/节气日历表 | `js/table.js`,源自 [JJonline/calendar.js](https://github.com/JJonline/calendar.js) v0.0.7(含社区对 2033 等年份的修正),经春节/中秋/端午等多锚点校验 |
| 节气时分 | 内置 VSOP87 截断级数自行推算,与天文历公开发布值核对一致 |
| 伊斯兰历 | 表格历法(舆图算法),实际日期以新月观测为准,可能有 ±1 日差 |
| 宜忌/占卦 | 民俗文化演绎,仅供品读娱乐 |
